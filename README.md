# Brainora — Intercampus Reciprocal Learning Platform

Brainora is a modern, responsive intercampus learning platform designed for university students to share, evaluate, and access study resources (lecture notes, algorithm blueprints, formula cheat sheets, and video tutorials) in a reciprocal credit-based ecosystem.

## 🚀 Features

- **Dashboard**: Overview with summary cards for credits earned, resources shared, resources accessed, and average rating. Includes recent activity and recommended resources.
- **Uploads**: Share study materials in three formats: **PNG**, **PDF**, and **MP4**. File upload drag-and-drop area with attribution fields (Name, Email, Department, Year, Section).
- **Resources Hub**: Discover tutorials, lecture notes, visual cheat sheets, and video tutorials. Search, department filtering, format pills, and interactive preview modal.
- **Ratings & Reviews**: Peer ratings, written feedback, and rating distribution breakdowns.
- **Student Profile**: Academic profile details, contribution stats, badges, and shared resource management.

## 🎨 Design

- **Frosted Glassmorphism**: High-contrast, readable dark navy and deep teal typography on frosted glass panels with subtle turquoise borders and ambient gradients.
- **Fully Responsive**: Adapts seamlessly from desktop down to mobile with collapsible navigation.

## 🛠️ Tech Stack

- **HTML5** & **Vanilla CSS** (No external framework dependencies)
- **Vanilla JavaScript** (Modular client-side store with LocalStorage persistence)

## 💻 Running Locally

You can serve the project using any local HTTP server:

```bash
# Python
python -m http.server 3000

# or Node / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
